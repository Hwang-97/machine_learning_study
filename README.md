# 머신러닝 학습 예제 2: 사고 텍스트 분류 및 대응 방안 추천

이 프로젝트는 자연어 처리(NLP) 기술을 이용해 주어진 텍스트(사고 내용)를 분석하여 **사고 유형을 분류**하고, 그에 맞는 **대응 방안을 추천**하는 머신러닝 모델을 만듭니다.

이 브랜치(`02-accident-prediction-classic`)에서는 전통적이고 고전적인 NLP 기법인 `KoNLPy`와 `TF-IDF`를 사용합니다.

## 📖 핵심 개념 및 구현 원리

머신러닝 모델은 사람의 언어(텍스트)를 직접 이해할 수 없습니다. 따라서 우리는 텍스트를 모델이 이해할 수 있는 **숫자(벡터, Vector)**로 변환하는 과정을 거쳐야 합니다. 이 프로젝트의 핵심은 바로 이 '텍스트의 벡터화' 과정에 있습니다.

### 텍스트 벡터화 파이프라인

우리의 모델은 다음과 같은 파이프라인(Pipeline)을 통해 텍스트를 처리하고 학습합니다.

`"폭설로 도로 마비"` (텍스트) → `[토큰화]` → `['폭설', '로', '도로', '마비']` → `[벡터화]` → `[0.0, 0.8, 0.0, ..., 0.6]` (숫자 벡터) → `[모델 학습]`

#### 1. 토큰화 (Tokenization) - "텍스트를 의미있는 단어로 쪼개기"

-   **문제점**: 단순히 띄어쓰기로 단어를 나누면 "차가미끄러져서" 같은 단어나, "사고가"와 "사고는"을 다른 단어로 인식하는 문제가 발생합니다.
-   **해결책**: **형태소 분석기**를 사용해 문장을 의미의 최소 단위인 '형태소'로 나눕니다.
-   **선택**: `KoNLPy` 라이브러리의 `Okt` 형태소 분석기를 사용했습니다. `Okt`는 준수한 성능을 보여주며, 특히 '어간 추출(Stemming)' 기능을 지원하여 "미끄러졌다", "미끄러져서"를 모두 원형인 "미끄러지다"로 통일해줍니다. 이는 단어의 수를 줄여 모델의 효율성을 높이는 데 큰 도움이 됩니다.
    -   **참고**: [KoNLPy 공식 문서](https://konlpy.org/ko/latest/)

#### 2. 벡터화 (Vectorization) - "단어의 중요도를 계산하여 숫자로 표현하기"

-   **문제점**: 어떤 단어가 중요한지 어떻게 알 수 있을까요? 단순히 단어의 등장 횟수만 세는 것(Count Vectorizer)은 "그리고", "그래서" 처럼 자주 나오지만 의미는 없는 단어에 높은 가중치를 부여하는 문제가 있습니다.
-   **해결책**: **TF-IDF (Term Frequency-Inverse Document Frequency)** 기법을 사용합니다.
    -   **TF (단어 빈도)**: 한 문서 안에서 특정 단어가 얼마나 자주 나오는가? (높을수록 중요)
    -   **IDF (역문서 빈도)**: 특정 단어가 전체 문서들에서 얼마나 공통적으로 나오는가? (높을수록(즉, 여러 문서에 나올수록) 중요도가 낮아짐)
-   **선택**: `scikit-learn`의 `TfidfVectorizer`를 사용했습니다. 이 방법은 특정 사고 유형(예: '자연재해')에서만 자주 등장하는 "폭설", "블랙 아이스" 같은 단어에는 높은 가중치를, 모든 문서에 흔하게 등장하는 "차량", "사고" 같은 단어에는 낮은 가중치를 부여하여 모델이 핵심 단어에 집중하도록 만듭니다.
    -   **참고**: [Scikit-learn TfidfVectorizer 설명](https://scikit-learn.org/stable/modules/generated/sklearn.feature_extraction.text.TfidfVectorizer.html)

#### 3. 파이프라인 (Pipeline) - "전처리부터 학습까지 한번에"

-   **문제점**: 모델을 학습시킬 때와 새로운 데이터로 예측할 때, 똑같은 전처리(토큰화, 벡터화) 과정을 매번 반복해야 합니다. 이 과정에서 실수가 발생하기 쉽습니다.
-   **해결책**: `scikit-learn`의 `Pipeline`을 사용해 모든 단계를 하나의 컨베이어 벨트로 묶습니다.
-   **장점**:
    1.  **일관성**: 학습과 예측 시 동일한 전처리 과정을 보장하여 실수를 방지합니다.
    2.  **편의성**: `pipeline.fit()` 한 줄로 학습이, `pipeline.predict()` 한 줄로 예측이 가능해집니다.
    3.  **재사용성**: 이 `pipeline` 객체 하나만 파일로 저장하면, 전처리 방법과 학습된 모델을 통째로 저장하고 불러올 수 있습니다.

## 🚀 사용법

[Poetry 설치](https://python-poetry.org/docs/#installation) 및 `konlpy` 사용에 필요한 Java 설치가 선행되어야 합니다.

### 1. 환경 설정
-   **Windows**: `install.bat` 파일을 더블 클릭하여 실행하세요.
-   **Linux/macOS**: 터미널에서 `./install.sh` 를 실행하세요. (실행 권한이 없다면 `chmod +x *.sh` 명령으로 권한을 부여하세요.)

### 2. 모델 학습
-   **Windows**: `train.bat` 파일을 더블 클릭하여 실행하세요.
-   **Linux/macOS**: 터미널에서 `./train.sh` 를 실행하세요.
-   > 이 과정을 통해 `data/accident_data.csv`를 학습하여 `models/accident_model.pkl` 파일이 생성됩니다.

### 3. 새로운 데이터 예측
-   **Windows**: `predict.bat` 파일을 더블 클릭하여 실행하세요.
-   **Linux/macOS**: 터미널에서 `./predict.sh` 를 실행하세요.
-   > `src/predict.py` 파일에 정의된 새로운 문장들의 사고 유형을 예측하고 대응 방안을 추천합니다.
